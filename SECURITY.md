# Security Policy

## Supported Versions

The table below outlines which versions of **Docket** are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of **Docket** seriously. If you discover a security vulnerability or potential issue, please follow these steps:

1. **Do NOT open a public GitHub issue** to report security vulnerabilities.
2. Email your findings directly to the repository maintainers or use GitHub Private Vulnerability Reporting.
3. Include as much detail as possible:
   - Type of issue (e.g., HTML injection, dependency risk, file system traversal)
   - Steps to reproduce
   - Potential impact
   - Suggested mitigations (if known)

### Response Timeline

- **Initial Acknowledgment**: Within 48 hours.
- **Triage & Status Update**: Within 7 business days.
- **Fix Release**: Vulnerability fixes will be released in a patch release as soon as possible after verification.
